# 🧼 RUEHL-REIN Website

Offizielle Website für den Reinigungsservice **RUEHL-REIN**.

---

## 🌍 Projektübersicht

Diese Website dient als Online-Präsenz für Dienstleistungen im Bereich:

* Gebäudereinigung
* Privatkunden-Reinigung
* Gewerbekunden-Reinigung
* Gartenservice

Ziel ist eine klare, moderne und mobiloptimierte Darstellung der Leistungen sowie einfache Kontaktaufnahme.

---

---

## 🚀 Projekt lokal starten

Einfach die `index.html` im Browser öffnen:

```
Doppelklick auf index.html
```

Oder über einen lokalen Server:

```
python3 -m http.server 5500
```

Dann im Browser:

```
http://localhost:5500
```
